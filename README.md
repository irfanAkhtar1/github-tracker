# 🚀 GitHub Tracker CLI

My first Node.js project — a simple command-line tool that fetches GitHub user data using the GitHub API.

---

## 📌 What it does

This CLI tool lets you:

- View a user's **recent GitHub activity (events)**
- View a user's **public repositories**
- Run everything directly from the terminal

---

## ⚙️ Built With

- Node.js
- JavaScript (ES6)
- GitHub REST API
- CLI (Command Line Interface)

---

## 🧠 What I learned

This project helped me understand:

- How Node.js runs outside the browser
- Working with APIs using `fetch`
- Async / Await in real use cases
- Handling JSON data
- CLI inputs using `process.argv`
- Basic backend thinking
